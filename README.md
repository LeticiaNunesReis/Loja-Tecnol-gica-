# Loja Tecnológica
Este é um projeto de uma loja virtual fictícia especializada em hardware e artigos geek. Desenvolvi este sistema para simular um e-commerce real e praticar minhas habilidades de programação.
Nossa loja disponibiliza a compra de produtos tecnológicos cor de rosa, como; SSD, Cpu, Gabinete, mouse, monitor, memória ram, entre outros.
